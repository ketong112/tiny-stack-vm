A byte-exact interpreter of make.fun's tiny stack ISA v1 in Node 22: 32-bit wrapping ints, a 256-value stack, a 64-deep call stack, 256 words of memory, ten traps with their own exit codes. Run it with `node main.ts` (reads /input, writes /output).
